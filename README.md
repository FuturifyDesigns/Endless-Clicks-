# Endless Clicks

Event hosting, planning, and advertising site for **Endless Clicks Pty Ltd**.

Live site: [https://futurifydesigns.github.io/Endless-Clicks-/](https://futurifydesigns.github.io/Endless-Clicks-/)

## Features

- Upcoming event countdown that flips to **Event is live**, then advances to the next queued event
- Guest registration (name + key details) with live attendance counts
- Admin control room to add/publish events and review registrations
- React + GSAP motion, navy/orange brand system from the EC Orbit Ticket logo

## Stack

- React (Vite)
- GSAP + `@gsap/react`
- Supabase (events, registrations, auth)
- GitHub Pages

## Local development

```bash
npm install
npm run dev
```

## Deploy

```bash
npm run deploy
```

## Admin

Sign in at `/#/admin` with the Endless Clicks admin account created in Supabase Auth.
